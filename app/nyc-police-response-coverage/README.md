# NYC Police Response Coverage

This directory is a deployable ArcGIS Nova app bundle.

Upload the entire directory to your web server. The entry file is `index.html`; do not upload only the entry file.

This bundle uses ArcGIS browser OAuth. The OAuth redirect URL is https://kikitamap.com/app/nyc-police-response-coverage.

The bundle contains no ArcGIS token, authorization header or client secret. If the app is edited in ArcGIS Nova after this bundle is created, run Deploy app again to create a fresh deployable snapshot.
